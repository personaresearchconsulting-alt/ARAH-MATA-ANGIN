1. Tingkat Dasar

Set 1 — Simulasi Mudah

Fokus pada penguatan konsep arah dasar, posisi relatif sederhana, dan perpindahan 1-2 langkah.

2. Tingkat Sedang

Set 2 — Simulasi Sedang

Latihan rotasi sudut majemuk, perhitungan jarak Pythagoras standar, serta rute 3 belokan.

3. Tingkat Sukar

Set 3 — Simulasi Sukar

Soal tingkat tinggi: penalaran multi-langkah kompleks, rotasi sudut lanjutan, dan denah multi-objek.

4. Simulasi Realistis

Set Campuran (Randomize)

Simulasi penuh 50 soal acak dari seluruh tingkat kesulitan dengan timer 45 menit untuk menguji kesiapan tes real.
